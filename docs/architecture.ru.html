InternetIPTaskbar 2.0.0

Архитектура проекта · показывает на панели задач внешний IP и флаг страны · WinForms, .NET 8

Приложение без главного окна: живёт в трее и рисует маленькое окно «флаг + IP» над панелью задач. Код разделён на три части: фоновый опрос сети (IpMonitor), неизменяемый снимок состояния (Snapshot) и интерфейс (TrayApp, OverlayForm). Всё работает в одном процессе.

3. Одна проверка: от триггера до экрана

Что запускает проверку

  • таймер (интервал 1/3/5/30/60 с, по умолчанию 30);
  • NetworkChange: через 2 и 8 с после включения/выключения VPN;
  • меню «Проверить сейчас», смена настроек.

Нагрузка на сервисы

  • обычная проверка — 2 запроса;
  • страна и провайдер — только при смене IP;
  • IPv6 — раз в 10 минут или при событии сети;
  • каждый запрос на новом соединении.

6. Сборка и поставка

7. Решения, которые стоит знать

Потоки

Состояние живёт только в фоновой задаче; наружу уходят неизменяемые Snapshot, поэтому блокировок в интерфейсе нет. Reevaluate() пересчитывает тревогу из последнего снимка без обращения к сети.

Устойчивость

Каждый запрос на новом соединении (Connection: close): иначе после смены VPN запрос мог бы пойти по старому маршруту. Сбой → серый IP, три подряд → «нет сети».

Окно

Обычная форма с WS_EX_NOACTIVATE | TOOLWINDOW. Пустой ContextMenuStrip WinForms молча не показывает, поэтому меню строится перед показом.

Один экземпляр

Мьютекс без версии — после обновления не работают две копии. Для тестов вторую копию собирают с другим именем мьютекса и папкой данных.

8. Известные ограничения

  • Поддерживается только основная панель задач; на Windows 11 и при нескольких мониторах поведение не проверялось.
  • Автоматических тестов нет: логика проверялась вручную, отдельными тестовыми программами и запуском приложения.
  • Установщик не подписан цифровой подписью — SmartScreen и антивирусы могут предупреждать.
