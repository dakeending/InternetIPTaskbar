Маленькая утилита для Windows: показывает на панели задач ваш **внешний IP-адрес и флаг страны**, из которой вы выходите в интернет. Сделана для контроля VPN: видно, включён ли он, и может предупредить, если VPN отвалился.

![Окно с IP на панели задач и меню в трее](docs/screenshot.jpg)

## Возможности

- **Окно «флаг + IP»** рядом с областью уведомлений (или по центру панели). Щелчок по нему открывает меню. Не берёт фокус и прячется в полноэкранных играх и видео.
- **Значок в трее** с флагом; в подсказке IP, страна и провайдер. Двойной щелчок копирует IP.
- **Надёжное определение:** два сервиса параллельно, третий только при расхождении. Страна и провайдер запрашиваются только при смене IP.
- **Мгновенная реакция на VPN:** программа слушает события сети и проверяет IP сразу после включения или выключения VPN (плюс обычный интервал: 1, 3, 5, 30 или 60 с).
- **Контроль VPN:** запомните реальный IP или страну (при выключенном VPN). Если выйдете в сеть под ними, окно станет красным и придёт уведомление; по желанию добавляется двойной пароходный гудок.
- **Подсказка об утечке IPv6:** показывает IPv6 и предупреждает, если он из другой страны, чем IPv4.
- **Честные состояния сбоя:** устаревший IP серый, а вместо вводящего в заблуждение старого адреса показывается «нет сети».
- **DPI по мониторам, светлая и тёмная темы, любая сторона панели, автоскрытие панели.**
- Интерфейс на английском и русском (по языку отображения Windows).

## Установка

Скачайте `InternetIPTaskbar_Setup_vX.Y.Z.exe` со страницы [Releases](https://github.com/dakeending/InternetIPTaskbar/releases) и запустите.

- Права администратора не нужны, ничего дополнительно ставить не требуется (среда .NET внутри).
- Установщик **не подписан цифровой подписью**, поэтому SmartScreen может предупредить: нажмите «Подробнее» → «Выполнить в любом случае». Контрольную сумму SHA-256 можно сверить со страницей релиза.
- Требования: Windows 10 (1607 и новее) или Windows 11, 64-разрядная, доступ в интернет.

Удалить можно через «Параметры → Приложения», из меню «Пуск» или из меню трея («Настройки → Удалить программу…»).

## Использование

Правый щелчок по значку в трее (или щелчок по окну с IP) открывает меню.

| Пункт меню | Что делает |
|---|---|
| Копировать IP / IPv6 | Копирует адрес в буфер обмена |
| Проверить сейчас | Запускает проверку немедленно |
| Настройки → Интервал проверки | 1, 3, 5, 30 или 60 секунд (по умолчанию 30) |
| Настройки → Положение | Рядом с областью уведомлений или по центру |
| Настройки → Контроль VPN | Выключен / тревога по реальному IP / по реальной стране; запомнить или забыть реальные значения |
| Настройки → Гудок при тревоге VPN | Двойной пароходный гудок при тревоге (по умолчанию выключен) |
| Настройки → Проверять IPv6 | Показывать IPv6 и предупреждать об утечке |
| Настройки → Запускать при входе в Windows | Автозапуск |
| Настройки → Подробный лог / Удалить программу… | Диагностика и удаление |
| Открыть лог | Открывает `app.log` в Блокноте |

Настройки хранятся в `%LOCALAPPDATA%\InternetIPTaskbar\settings.json`.

## Приватность

Программа обращается только к публичным сервисам: `api.ipify.org`, `ipv4.icanhazip.com`, `checkip.amazonaws.com`, `api6.ipify.org` (IPv6), `ipinfo.io`, `ipwho.is`, `ipapi.co` (геоданные) и `flagcdn.com` (флаги, если не вшиты). Телеметрии нет, собственного сервера и аккаунтов нет. Запомненный «реальный» IP хранится только в `settings.json` на вашем компьютере. В логе есть смены IP, поэтому просмотрите его перед тем, как делиться.

## Сборка из исходников

Нужны: Windows, [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0) и (для установщика) [Inno Setup 6](https://jrsoftware.org/isinfo.php).

```powershell
git clone https://github.com/dakeending/InternetIPTaskbar.git
cd InternetIPTaskbar
dotnet build -c Release
dotnet test -c Release
```

Установщик (сначала публикуется одиночный self-contained exe):

```powershell
.\scripts\fetch-flags.ps1      # по желанию: вшить ~250 флагов в exe
.\scripts\build-installer.ps1  # -> artifacts\InternetIPTaskbar_Setup_v<версия>.exe
```

Версия задаётся в одном месте: `<Version>` в `src/InternetIPTaskbar/InternetIPTaskbar.csproj`.
