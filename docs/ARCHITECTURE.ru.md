# Архитектура InternetIPTaskbar 2.0.0

[English](ARCHITECTURE.md) · **Русский**

WinForms-приложение на .NET 8 без главного окна. Код разбит на слои: фоновый опрос сети, неизменяемый снимок состояния, интерфейс. Всё в одном процессе, работает только в трее.

Визуальная версия с диаграммами: [ARCHITECTURE.ru.pdf](ARCHITECTURE.ru.pdf) (исходник — [architecture.ru.html](architecture.ru.html), сборка — `scripts/make-architecture-pdf.ps1`).

## Общая схема

```
                       ┌──────────────────────── UI-поток (WinForms) ───────────────────────┐
 Program.cs ──────────►│ TrayApp (ApplicationContext, «сборщик» всего)                      │
 (мьютекс, лог          │  ├─ OverlayForm      окно «флаг + IP» над панелью задач            │
  необработанных        │  │    ├─ Taskbar / FullscreenDetector   положение, скрытие         │
  исключений)           │  │    └─ NativeMethods (WinAPI)                                    │
                       │  ├─ NotifyIcon + ContextMenuStrip   значок и меню                  │
                       │  ├─ таймер 1 с  → overlay.RefreshLayout()                          │
                       │  ├─ FlagStore    флаг: ресурсы → кэш → сеть                        │
                       │  └─ Autostart, HornSound, Settings                                │
                       └───────────────▲────────────────────────────────────────────────────┘
                                       │ Snapshot (неизменяемая запись) через ui.Post
                       ┌───────────────┴────────── фоновая задача ──────────────────────────┐
                       │ IpMonitor: цикл проверок, состояния, тревога, события сети         │
                       │   └─ IpClient (HTTP): IPv4-голосование, IPv6, геоданные + кэш      │
                       └────────────────────────────────────────────────────────────────────┘
        Сквозные: Settings (JSON), Log (файл с ротацией), AppInfo (версия, пути)
```

## Модули

| Файл | Роль |
|---|---|
| `src/InternetIPTaskbar/Program.cs` | Точка входа. Мьютекс `InternetIPTaskbar.SingleInstance` (без версии), перехват необработанных исключений в лог, запуск `TrayApp`. |
| `src/InternetIPTaskbar/TrayApp.cs` | Корень композиции. Создаёт настройки, монитор, окно и значок; получает `Snapshot` от монитора и раздаёт его окну, значку и подсказке. Собирает меню, грузит флаги, показывает уведомления, играет гудок, управляет автозапуском и удалением. |
| `src/InternetIPTaskbar/IpMonitor.cs` | Единственный источник истины о сети. Фоновый цикл: проверка → пауза до следующей (или досрочный сигнал). Состояния `Starting / Ok / Stale / Offline`, расчёт тревоги и IPv6-несоответствия. Выдаёт неизменяемые `Snapshot`. |
| `src/InternetIPTaskbar/IpClient.cs` | Статический сетевой слой. IPv4 по двум сервисам, третий только при расхождении; IPv6; геоданные цепочкой ipinfo → ipwho.is → ipapi.co с кэшем по IP. |
| `src/InternetIPTaskbar/FlagStore.cs` | Флаг страны: сначала ресурс внутри exe (`Flags\*.png`), затем кэш на диске, затем flagcdn.com. Битый файл кэша удаляется, на диск пишется только то, что декодировалось. |
| `src/InternetIPTaskbar/OverlayForm.cs` | Только отображение: рисует флаг (с тонкой белой каймой) или код страны и текст, считает размер и положение, цвет плашки по состоянию (зелёный / серый / оранжевый) и мигание тревоги 3 Гц в течение 10 с. Не берёт фокус, щелчок открывает меню. |
| `src/InternetIPTaskbar/Strings.cs` | Весь текст интерфейса на английском, русском и традиционном китайском (Гонконг); язык берётся из Windows или выбирается в меню. |
| `src/InternetIPTaskbar/IpRange.cs` | Помощники для IPv4 CIDR: подсеть /24 запомненного реального IP и проверка вхождения для режима тревоги «диапазон IP». |
| `src/InternetIPTaskbar/Taskbar.cs` | Положение панели задач (любая сторона, автоскрытие, область уведомлений) и определение полноэкранного приложения. |
| `src/InternetIPTaskbar/NativeMethods.cs` | P/Invoke: окна, панель задач, ярлыки, иконки. |
| `src/InternetIPTaskbar/Settings.cs` | JSON в `%LOCALAPPDATA%\InternetIPTaskbar\settings.json`, атомарная запись, допустимые интервалы 1/3/5/30/60 с. |
| `src/InternetIPTaskbar/Log.cs` | Файл с ротацией 3 × 1 МБ; Info всегда, Debug по флагу. |
| `src/InternetIPTaskbar/Autostart.cs` | Автозапуск через `HKCU\...\Run`, учитывает отметку «отключено» в диспетчере задач и старый ярлык 1.9.x. |
| `src/InternetIPTaskbar/HornSound.cs` | Двойной гудок, синтезируется в WAV при первом вызове. |
| `src/InternetIPTaskbar/AppInfo.cs` | Версия из сборки, User-Agent, папка данных. |

## Поток данных

1. `IpMonitor` в фоне опрашивает сервисы. Источники запуска проверки: таймер интервала, `NetworkChange` (включение или выключение VPN, проверки через 2 и 8 секунд), ручной пункт «Проверить сейчас», смена настроек.
2. Результат складывается в `Snapshot`: IP, страна/провайдер/город, IPv6, состояние, признак тревоги, признак расхождения IPv6.
3. Монитор вызывает событие `Changed`. `TrayApp` через `SynchronizationContext.Post` переносит снимок в UI-поток.
4. В UI-потоке: окно перерисовывается, обновляются значок и подсказка. Если страна сменилась, старый флаг сразу убирается и грузится новый (проверка по стране защищает от запоздавшего ответа). На переход в тревогу: уведомление, по настройке гудок.
5. Таймер на 1 секунду отдельно пересчитывает положение окна, скрывает его при полноэкранных приложениях или скрытой панели и поднимает над панелью задач.

## Состояния сети

| Состояние | Когда | Что видно |
|---|---|---|
| `Starting` | запуск, первой проверки ещё не было | «…» |
| `Ok` | последняя проверка удалась | IP и флаг |
| `Stale` | запрос не удался (1–2 раза подряд) | прежний IP серым |
| `Offline` | 3 неудачи подряд или сеть недоступна | «нет сети» |

После сбоя повтор идёт каждые 5 секунд (вместо обычного интервала); любой успех возвращает в `Ok`. **Тревога** (`Alert`) — отдельный признак поверх `Ok`/`Stale`: IP, диапазон IP (/24 запомненного адреса) или страна совпали с запомненными «реальными» (по выбранному режиму). Плашка 10 секунд мигает ярко-оранжевым с частотой 3 Гц и затем остаётся оранжевой; показывается уведомление, по настройке играет гудок.

Цвета плашки: **зелёный** для `Ok` и `Stale` (при `Stale` текст приглушён), **серый** для `Starting` и `Offline`, **оранжевый** при тревоге.

## Решения, которые стоит знать

- **Потоки.** Состояние живёт только в фоновой задаче; наружу уходят неизменяемые `Snapshot`, поэтому блокировок в UI нет. `Reevaluate()` пересчитывает тревогу из последнего снимка без сети.
- **Нагрузка.** Основная проверка: 2 запроса. Страна и провайдер только при смене IP, с повтором не чаще раза в минуту. IPv6 раз в 10 минут или при событиях сети. Публикация IPv4 идёт до проверки IPv6, чтобы таймаут не задерживал показ IP.
- **Устойчивость.** Каждый запрос на новом соединении (`Connection: close`), иначе после смены VPN запрос мог бы идти по старому маршруту.
- **Окно.** Главная форма, но с `WS_EX_NOACTIVATE | TOOLWINDOW`. Пока меню открыто, окно «на паузе» и не поднимается поверх него. Меню перед показом строится явно: пустой `ContextMenuStrip` WinForms молча не показывает.
- **Мьютекс** без версии, чтобы после обновления не работали две копии. Для тестов вторую копию приходится собирать с другим именем мьютекса и папкой данных.

## Сборка и поставка

- `InternetIPTaskbar.csproj`: версия единственный раз (`<Version>`), `PerMonitorV2`, публикация одним сжатым self-contained exe (около 68 МБ), `Flags\*.png` вшиваются как ресурсы, иконка `Assets\app.ico`.
- `Installer\InternetIPTaskbar.iss` (Inno Setup): версия читается из exe, установка в профиль без прав администратора, чистит файлы 1.9.x, автозапуск через реестр, ярлык «Удалить», вопрос про удаление данных при деинсталляции.
- `scripts/build-installer.ps1` публикует и собирает установщик. Рядом: `make-icon.ps1`, `fetch-flags.ps1`, `make-architecture-pdf.ps1`. Выпуск релизов — `docs/RELEASING.md`, CI — `.github/workflows`.
- Данные в рантайме: `%LOCALAPPDATA%\InternetIPTaskbar` (настройки, `logs\`, кэш `flags-w80\`). Проект под git, история с исходной 1.9.5.

## Известные ограничения

- Поддерживается только основная панель задач; на Windows 11 и при нескольких мониторах поведение не проверялось.
- Автоматических тестов нет: логика проверялась вручную, отдельными тестовыми программами (автозапуск, звук) и запуском приложения.
- Установщик не подписан цифровой подписью, поэтому SmartScreen и антивирусы могут предупреждать.
